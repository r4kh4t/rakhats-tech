# Working on rakhats.tech

This is Rakhat Shakimbekov's personal portfolio and blog. Build with `npm run build`; verify generated pages and content with `npm run check`. Preview with `npm run dev` on port 4321.

Keep it dependency-free, accessible, fast, responsive, and statically deployable on Vercel. Source content lives in `content/posts/*.json`. Do not edit `dist/` directly. Keep canonical URLs, RSS, sitemap, and source attributions intact. LinkedIn imports are manual, authored posts only; do not present other people's reposts as Rakhat's writing. Never invent roles, dates, certifications, metrics, or client names. Do not expose private repositories or publish resumes/contact data that are not already public without user authorization.

The domain uses external DNS at manage.get.tech. Prefer targeted DNS record updates over nameserver changes, preserving email and unrelated records. No paid services or credentials are required by the site.
